每日一語 · Naval Ravikant
每天自動顯示一條納瓦爾·拉維肯的真實語錄，附中文說明。
功能
	•	100 條真實語錄，全部來自《The Almanack of Naval Ravikant》及其 Twitter、Podcast
	•	每天自動換一條，數十年不重複
	•	背景配色每天輪換
	•	無需 API、無需後端、純靜態網頁
部署
	1.	Fork 或 Clone 此 repo
	2.	進入 Settings → Pages
	3.	Branch 選 main，資料夾選 / (root)
	4.	儲存後等幾分鐘，網址即上線
語錄來源
	•	The Almanack of Naval Ravikant by Eric Jorgenson
	•	Naval Ravikant Twitter
	•	Naval Ravikant Podcast 訪談
